# Known limitations and accepted risks

This page collects, for auditors, every known limitation and accepted risk of 6529 Works v1
that the ADRs, the module READMEs, the architecture document and the deployment runbook
record, stated against the code on `main`. Each row says what the limitation is, what follows
from it, what mitigates it or which operating procedure covers it, and where it is recorded.
Nothing here is a finding of the external audit, which has not happened.

> **Status.** Pre-audit. This page describes `main` at `46941d6` (15 October 2026). The ADRs
> record how the design was decided; this page is how it works now. Where they differ, this
> page follows the code and says so under [Differences from the ADRs](#differences-from-the-adrs).

## How to read this page

Each row has a type:

| Type | Meaning |
| --- | --- |
| **Accepted risk** | A risk recorded as accepted or residual by an ADR, an owner decision, or a module README's residual-risk section. Changing it needs a design decision. |
| **Known gap** | Something described as not implemented, a v1 limitation or a gap. It may be fixed later without reopening a decision. |

Delay classes are those of [`Roles.sol`](../../src/governance/Roles.sol): immediate, standard
(48 hours), funds (14 days) and successor (30 days). The role table is on
[Roles](roles.md).

## Differences from the ADRs

- **ADR 0001, accepted risks:** "Starting bids at 0 can produce very low sale prices." ADR
  0003 made the first bid at least `max(openingBid, 1 wei)`, and `EnglishAuction` enforces it,
  so a zero bid cannot claim a work; the accepted risk is now a 1 wei sale (LIM-SAL-1).
- **ADR 0001 §13.9, raise-only gas parameters:** the VRF callback limit can also be lowered,
  never below `MIN_CALLBACK_GAS`, in the 30-day class (`lowerCallbackGasLimit`, ADR 0003,
  DEPS-5).
- **ADR 0001 §8 storage figures** (about 0.23 ETH per MB per gwei, about 72 KB per transaction)
  predate Glamsterdam; ADR 0004 records about 1.65 ETH per MiB at 1 gwei and one full chunk per
  transaction (LIM-GAS-9).
- **ADR 0001 §16** states that royalties are advisory for federated contracts. Stream and
  Editions likewise implement only ERC-2981, so the same holds for them (LIM-SAL-8).
- **The EIP-7825 rule.** ADR 0003 and the content README first stated that every transaction
  fits 16,777,216 gas. ADR 0004 decision 4 restates it for regular gas only (LIM-GAS-2).
- **Lifting a suspension.** The ADR 0002 addendum names an ADMIN grant, or a revocation and a
  new grant, as the lift. In the code a revocation alone lifts it, and so does the holder's own
  `renounceRole`, which OpenZeppelin runs through `_revokeRole` (LIM-GOV-14;
  `test_ARevocationClearsItAndTheKeyCanRenounce`).
