# 6529 Works v1.0.0-rc.3

Release candidate 3 of 6529 Works v1, 23 November 2026. Its contracts, deploy and verify scripts,
genesis policy and compiler settings are the code deployed as Sepolia r8 (`961bc956`).

> **Pre-audit. Not production-ready.** Do not use this code to custody value. No external audit
> has started, and there is no mainnet deployment. Sepolia r8 is a testnet rehearsal with
> throwaway signers.

No `v1.0.0-rc.3` tag existed before this one. Some ADRs (0004, 0005 §13 and 0007) use "rc.3"
for work planned after rc.2; that work was never tagged, and this release replaces part of it.

## What v1 is

6529 Works is the 6529 network's art protocol. **6529 Stream** is one shared ERC-721 for curated
1/1 artworks, and **6529 Stream Editions** is one shared ERC-1155 whose editions are each
anchored by a Stream work. **6529 Independent Stream** and **6529 Independent Stream Editions**
are an artist's own pair of contracts, built from the same code and listed by the network
without the curation vote. Sales are in ETH only: an English auction for a 1/1 that anyone may
start and settle, and a uniform-price auction for its editions. Money moves by pull through
immutable split vaults, and a payment that fails waits in an escrow for its owner.

A small set of **permanent** contracts holds only who owns which token, the facts of a finished
work and money already owed. Their code is plain. Everything that is a rule lives in
**replaceable modules**, which the network adds after a waiting period (a network setting, 7
days at launch) and removes at once ([ADR 0010][adr10]). The [overview][overview] describes the
system in three pages.

## What changed since rc.2

Every change, grouped by area, is in the [changelog][changelog]. In short:

- **The plain permanent core** ([ADR 0010][adr10]). The permanent contracts (`Stream6529`,
  `StreamEditions6529`, `StreamWorkFacts6529`, `StreamDirectory6529`, the split ledger and its
  vaults, the escrow, the content store) hold only token ownership and the collection address,
  the facts of a finished work and money already owed. Every rule moved to a replaceable module.
  The earlier `Stream`, `WorkRecords`, `Editions` and `ArtistRegistry` contracts, the English
  auction's lens and the earlier deploy and verify scripts are removed; they stay at the
  `v1.0.0-rc.2` tag.
- **Waiting periods are network settings.** Every wait in a permanent contract is a stored value
  with a launch value: `moduleDelay` 7 days, `rescueDelay` 14 days, `rebindDelay` 14 days,
  `unclaimedPeriod` 180 days. The network changes them at once, and each change is logged.
- **ETH only.** Sales are in ETH. The ERC-20 and Permit2 payment paths of the sale contracts
  are removed; the escrow and the split ledger keep their token paths.
- **Independent Stream** ([ADR 0008][adr8]). An artist's own token pair, minted only through
  sale contracts the Independent Stream module allows. An unsold Independent Stream work can be
  offered again.
- **Identity.** An artist or collaborator is a 6529 consolidated account, and every wallet of
  it acts (the `Accounts` module).
- **Final names.** The products are 6529 Stream, 6529 Stream Editions, 6529 Independent Stream
  and 6529 Independent Stream Editions; the token symbols are `6529STREAM` and
  `6529STREAMEDITIONS`.
- **Three module fixes** (`961bc956`). An edition sale no longer follows a 1/1 that is offered
  again; a fee recipient is never zero; the Independent Stream module refuses an entropy module
  without code. No permanent contract changed.

## Status

- **Pre-audit.** The code has been reviewed only by AI agents. That is not an audit, and no
  external audit has started.
- **Testnet only.** Three Sepolia instances run the plain core, all deployed on 23 November
  2026 with throwaway signers: r8, the current instance, from `961bc956`; r7, from `5de6abaa`,
  without the three module fixes; and r6, from `2aac8579`, kept with a renderer proposal
  pending for a module-swap test ([deployment records][deployments]). The rehearsals up to r5
  ran the code before the restructuring.
- **Mainnet:** not deployed.
- **Tests still being ported.** Some stateful invariant campaigns of the earlier contracts
  have not been ported to the plain core; the [invariants catalogue][invariants] lists them as
  placeholders, and the [testing guide][not-tested] says what is not tested.

The record also says what it did not run: no audit, mutation testing of every file, the hosted
workflows themselves, a live deployment, and platforms other than Linux.

**Sepolia r8** ([record][r8], [flows][flows-r8]). Deployed from `961bc956` on 23 November 2026.
`script/VerifyCore.s.sol` passed against the chain's head three times that day, the last after
128 flow transactions, and Sourcify holds an exact match for the runtime and creation code of
its 35 contracts. Its flows show an unsold Independent Stream work offered again beside its
edition sales, and the basics once: a curated 1/1 with a competing bid, its settlement and
`tokenURI`, an edition sale, and payouts. Flows behind a long wait (credit expiry, forfeit,
rescue, rebind, a finalize notice, an abandoned edition sale) were not run.

## Reproduce and verify

```bash
git clone --recurse-submodules https://github.com/6529-Collections/6529-works.git
cd 6529-works
git checkout v1.0.0-rc.3
forge build   # Foundry 1.7.1; solc 0.8.37, EVM prague, optimizer 200 runs, no via-IR
forge test --no-match-test "^invariant"
```

- **Same code as r8.** `git diff 961bc956 v1.0.0-rc.3 -- src script/DeployCore.sol
  script/DeployCore.s.sol script/VerifyCore.sol script/VerifyCore.s.sol script/CoreFactory.sol
  script/ScriptIO.sol script/DeployGuards.sol config/genesis.core.example.json foundry.toml
  foundry.lock lib` prints nothing. Under `config/`, the tag adds only r8's own copy (`config/sepolia-r8/`) and
  an update to `config/README.md`. The command lists the contracts, the deploy and verify
  scripts, the genesis policy, the compiler settings and the pinned libraries; other files
  did change since `961bc956`: two test files, the Sepolia flow
  scripts under `script/sepolia/`, `script/README.md`, tools, CI workflows, records and
  documentation.
- **Sourcify** holds an exact match for each of r8's 35 contracts.
- **[`VerifyCore.s.sol`][verify]** deploys the same build again in memory and compares every
  address and runtime code, the module slots, the minters, the settings, the stored
  configuration, the epoch-0 manifest and the governance configuration with the chain. r8 is
  kept as genesis installed it, so it can be run at the chain's head, from r8's source commit
  with the round's `deploy.env` ([how to check an instance][check]).

## Known limitations

Every one, with its source: [known limitations and accepted risks][lim]. Among them:

1. **Gas is budgeted in Prague gas.** Foundry cannot run Glamsterdam, so CI's figures do not
   bound what users pay; the Sepolia figures are hand measurements ([ADR 0004][adr4],
   LIM-GAS-1).
2. **The curation signer is trusted** until the 6529 chain: the verifier trusts its key, not
   the vote it reports (LIM-GV-1). Votes are off-chain, and one 6529 Safe holds the network
   address until the TDH bridge exists (LIM-GV-9, LIM-GV-18).
3. **The permanent contracts cannot be patched.** Every curated work lives in one Stream
   contract, which is not a proxy; only its modules change (LIM-GV-11).
4. **Modules are governed trust.** A module the network installs can set future royalties,
   draw works that are not finalized and edit records within what the core allows, and a
   minter can mint new tokens. No module can move a held token, change a fact fixed at mint or
   touch owed money (LIM-GV-17).
5. **Waiting periods are settings, not promises.** The network changes them at once, zero
   allowed (LIM-GV-30).

## For integrators

The plain core changes every address, ABI and interface ID of rc.2: rebuild from this tag. The
exported ABIs are in [`abi/`][abi]; the [integrator guide][integrators] covers reading a work,
bidding and settling, events and indexing, and the Sepolia addresses.
