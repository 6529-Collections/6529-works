# 6529 Works v1.0.0-rc.1

Release candidate 1 of 6529 Works v1, 16 October 2026. Its contracts, deploy and verify scripts,
genesis policy and compiler settings are the code deployed as Sepolia rehearsal r3 (`e5fe78c`).

> **Pre-audit. Not production-ready.** Do not use this code to custody value. No external audit
> has started, and there is no mainnet deployment.

## What v1 is

6529 Works is the 6529 network's art protocol. **6529 Stream** is one shared ERC-721 for curated
1/1 works; **6529 Editions** is one shared ERC-1155 whose editions are each anchored by a Stream
master. A work is approved by a TDH-weighted vote and attested by a curation signer, every party
named in it signs before it is sold, and anyone may start and settle its 24-hour English auction.
Proceeds and royalties are paid by pull into immutable split wallets, content is addressed by
hash and anyone may put it on-chain, and one OpenZeppelin `AccessManager` governs every contract
behind delays that guardians can veto.

## Reproduce and verify

```bash
git clone --recurse-submodules https://github.com/6529-Collections/6529-works.git
cd 6529-works
git checkout v1.0.0-rc.1
forge build   # Foundry 1.7.1; solc 0.8.37, EVM prague, optimizer 200 runs, no via-IR
forge test
```

- **Same code as r3:** `git diff e5fe78c v1.0.0-rc.1 -- 'src/**/*.sol' script/DeployV1.sol
  script/Deploy.s.sol script/DeployGuards.sol script/Verify.s.sol script/VerifyV1.sol
  config/genesis.example.json foundry.toml` prints nothing.
- **Sourcify** recompiles each contract from this source and its CBOR metadata (IPFS hash) and
  reports an exact match.
- **[`Verify.s.sol`][verify]** recomputes every r3 address from this build's creation code and
  the recorded constructor arguments (CREATE2), then reads back code hashes, the CC0 text, the
  manifest, holders, roles, delays and wiring. Until the manager's 5-day setback ends it stops
  at the first pending role delay (`RoleMismatch(0)`), after the address and code checks pass:

```bash
DEPLOYMENT=deployments/11155111/1792095396.json \
MANIFEST_PATH=config/sepolia-r3/manifest-epoch0.json \
  forge script script/Verify.s.sol --rpc-url "$SEPOLIA_RPC_URL"
```

## Known limitations

Every one, with its source: [known limitations and accepted risks][lim]. The top five:

1. **Gas is budgeted in Prague gas.** Foundry cannot run Glamsterdam, mainnet's parameters are
   not final, and the per-transaction cap's treatment of state gas rests on Sepolia (LIM-GAS-1,
   LIM-GAS-2).
2. **Fixed gas allowances were sized on Prague** and need re-checking on mainnet's parameters
   (LIM-GAS-5, LIM-GAS-6).
3. **The curation signer is trusted** until the 6529 chain: the verifier trusts its key, not
   the vote it reports (LIM-GV-1).
4. **One Stream contract, not upgradeable:** a defect in it reaches every work (LIM-GV-11).
5. **Recovery restrains the artist.** While an override that would move the authority is
   pending, nobody acts as the artist: through its 180-day notice, and up to a year more if it
   is contested (LIM-ID-2, LIM-ID-3).

## Breaking changes since r2, for integrators

Rebuild ABIs from this tag; the full list is under [changes since the Sepolia r2 build][changes].

- **Errors consolidated (#66).** `Dependency.InvalidDependency(address)`,
  `Dependency.DependencyCodeChanged(address)`, `SignatureVerifier.InvalidSignature(address)` and
  `SignatureVerifier.SignatureExpired(uint256)` replace more than a dozen per-contract errors,
  and `IStream.InvalidMintRequest` is split into one error per Stream rule. Error selectors
  change; no function selector or interface ID does.
- **`IMintSale`,** a new errors-only interface extended by `IFixedPriceSale` and `IDutchSale`,
  declares the errors only those adapters raise.
- **Curation approvals bind the signer's epoch:** `PackageApproval(bytes32 packageRoot,bytes32
  evidenceHash,uint256 signerEpoch)`. Read `signerEpoch(signer)` before signing; r2's two-field
  approvals do not verify.
- **New selectors and events,** among them `releaseContent` with a beneficiary (so
  `ContentReleased` has a new topic0), `SeedDelivered` indexed by content hash, `claimFor`,
  `scheduleDelay`, `formatOf`, `activeAuthorityOf`, `statusClock` and the guardians' `suspend`.
